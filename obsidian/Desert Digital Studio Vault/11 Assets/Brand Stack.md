# DDS Brand Stack

## Core brand
- Name: Desert Digital Studio
- Style: dark modern SaaS with amber accents
- Primary logo: Logo A
- Website: https://www.desertdigitalstudio.com

## Main stack
- Frontend: HTML, CSS, vanilla JavaScript
- Hosting: Vercel
- Repo: GitHub
- Ops: Node.js scripts + OpenClaw
- AI: GPT-5.4 + local Qwen via Ollama
- Email: Zoho Mail
- Invoicing: Wave

## Notes
- Keep messaging local, clear, and non-corporate
- Sell trust, clarity, and direct communication, not jargon
